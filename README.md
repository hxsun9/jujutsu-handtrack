# 무하한 핸드 주술 (jujutsu-handtrack)

웹캠으로 손을 인식해 **수인(손 모양)으로 주술을 쓰는** 브라우저 게임입니다. 첫 번째 캐릭터는 고죠 사토루의 무하한 주술을 모티프로 했어요. 설치 없이 HTML 파일 하나로 돌아갑니다.

## 플레이

- **온라인**: GitHub Pages가 켜져 있으면 `https://hxsun9.github.io/jujutsu-handtrack/` 에서 바로 플레이할 수 있어요.
- **로컬**: 이 폴더에서 `python -m http.server` 실행 → Chrome으로 `http://localhost:8000` 접속 (`index.html`이 게임입니다).
  파일을 더블클릭해서 열면 브라우저가 카메라를 막을 수 있어요.
- 웹캠이 없으면 **마우스로 연습**을 누르세요.

처음 시작하면 **수련장**에서 다섯 가지 술식을 익힌 뒤 실전으로 넘어갑니다.

## 술식과 수인

| 술식 | 수인 (카메라) | 연습 모드 | 효과 |
|---|---|---|---|
| 술식순전 「아오」 | 검지·중지를 붙여 세우고 나머지는 접기 | `1` 누르고 있기 | 적과 탄환을 끌어당겨 갈아버림 |
| 술식반전 「아카」 | 엄지·검지 총 모양 → 충전 후 휘두르기 | `2` 누른 채 마우스 휘두르기 | 발사 후 폭발. 1.6초 모으면 **최대출력** |
| 허식 「무라사키」 | 한 손 아오 + 다른 손 아카를 모으기 | `3` | 경로의 모든 것을 지우는 관통 일격 (주력 40) |
| 반전술식 | 손바닥 활짝 펴기 | `5` 누르고 있기 | 주력을 태워 체력 회복 |
| 영역전개 「무량공처」 | 검지 위로 중지를 꼬아 1초 (두 손 아오를 맞대도 됨) | `4` 1초 | 9초간 모든 적 정지·정리 (주력 90) |
| 무하한 | 자동 | — | 적과 탄환이 막 앞에서 멈춤. 버틸수록 주력 소모 |

`P`/`Esc` 일시정지 · `D` 수인 인식 수치 보기 · 조작법 패널에서 **수인 감도** 조절

## 적

일반 주령, 덩치, 질주형(지그재그), 원거리형(탄환 발사), 분열형, 그리고 5웨이브마다 **특급 주령**(파동·소환 패턴)이 나옵니다.

## 기술 스택

- 손 인식: [MediaPipe Hand Landmarker](https://developers.google.com/mediapipe/solutions/vision/hand_landmarker) (브라우저 안에서만 처리, 영상 전송 없음)
- 렌더링: Canvas 2D, 소리: Web Audio (외부 에셋 없음)
- 좌우 손 뒤바뀜 방지: 손목 위치 연속성으로 손 정체성 유지
- 떨림 보정: One Euro 필터

> 팬 메이드 비공식 게임입니다. 원작 캐릭터의 모습은 쓰지 않았고, 적과 이펙트는 직접 그린 오리지널 디자인입니다.
